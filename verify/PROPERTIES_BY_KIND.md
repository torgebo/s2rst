# What the proofs guarantee, by kind

Every property that `verify/` proves or tests, grouped by the kind of guarantee it gives, with
a plain-language statement first. This is the place to start browsing. The four catalogues
carry the exact statements against the models, the upstream sources, the bounds and the
mutants: [`PROPERTIES.md`](PROPERTIES.md) (`CellId`),
[`cell_union/PROPERTIES.md`](cell_union/PROPERTIES.md) (`CellUnion`),
[`decoding/PROPERTIES.md`](decoding/PROPERTIES.md) (the decoding layer) and
[`values/PROPERTIES.md`](values/PROPERTIES.md) (the value types: `Cell`, `s1::Interval`,
`r1::Interval`, `s2::Rect`, `r2::Rect`, `s2::Point`, `s1::ChordAngle`, `s1::Angle` and `s2::Cap`). The operation
inventories carry the crash-freedom proofs.

| Kind | It guarantees that… | Entries |
|------|---------------------|---------|
| [Never crashes](#never-crashes) | an operation finishes without a panic, an arithmetic overflow, undefined behaviour or a hang, whatever its input | every in-scope operation, plus 2 |
| [Correct result](#correct-result) | an operation returns what the model says it should | 146 |
| [Round trip](#round-trip) | converting a value there and back gives the original | 17 |
| [Exact output](#exact-output) | an encoder or printer writes exactly the bytes or text the format prescribes | 22 |
| [Exact input](#exact-input) | a decoder or parser accepts exactly the well-formed inputs, returns what they say, consumes exactly them and rejects the rest | 17 |
| [Validity](#validity) | a validity check answers exactly, and results are well formed | 14 |
| [Laws](#laws) | operations relate to each other as they must: symmetry, idempotence, order independence, partition, consistency | 39 |
| [Model checks](#model-checks) | the models and restated copies that the proofs compare against are themselves right | 5, plus the links |

## Browsing the code by kind

Each property harness's doc comment starts with its id and its kind in parentheses, then
the plain-language statement, then the exact statement:

```rust
/// P-HIER-01 (correct result): `children()` gives the cell's four children, in curve order.
///
/// `children()[k] == compose(child(d, k))` for `k < 4`.
```

So `grep -rn '(round trip)' verify/src` lists every round-trip proof, and the same works for
each kind. Crash-freedom harnesses start with their obligation, `C-<operation>:` (in `crash`,
`cu_crash`, `cd_crash` and `cd_xlarge`), and the bounded links to the Verus copies with
`Bounded agreement (model check)` (in `cd_agree`). `tests/property_kinds.rs` checks that every
catalogue entry is listed here exactly once and that the code's tags match this page.

## Words used

- **Cell, leaf, level, face.** A cell is a square on one of the six faces of the cube that S2
  projects the sphere onto. Level 0 is a whole face; each level splits every cell into four
  children; level 30 cells are leaves. A **valid** cell id is one that names such a cell.
- **Curve order.** All cells of one level lie along a space-filling (Hilbert) curve that runs
  over face 0, then face 1, and so on. A cell covers a contiguous run of leaves along it.
- **Union.** A `CellUnion` is a list of cells. It is **valid** when its cells are valid,
  sorted in curve order and do not overlap, and **normalised** when, in addition, no four
  consecutive cells are the four children of one parent (they would be replaced by it). A
  union **covers** a leaf if one of its cells contains it.
- **The models.** `src/spec.rs` (cells), `src/union_spec.rs` (unions, as the set of leaves they
  cover) and `src/wire_spec.rs` (the wire formats) are written from upstream S2, independent
  of the library, and tested against vectors generated by the C++ library.
- **Holds for.** *every* means the whole input domain. A bound such as *unions of up to 3
  cells* or *inputs up to 11 bytes* means the proof covers exactly those inputs; the
  catalogue names the tests that exercise larger ones. **Weekly** members run in the slow
  tier (`make verify-slow`), the rest on every change.
- **Kani and Verus.** Kani checks the library's own code within the bound. Verus proves a
  restated copy of a codec for every size; the copy is tied to the library by the
  [links](#links-between-the-verus-copies-and-the-library).

## Never crashes

No panic, arithmetic overflow, out-of-bounds access, undefined behaviour or hang, for every
input in the operation's documented domain. Kani checks for all of these in *every* harness,
so a property harness also proves its operation crash-free over its own domain; the
inventories say which harness discharges each operation.

### Panics exactly where documented

The proofs above stop at an operation's documented domain. These prove the rest of each
`# Panics` section (2026-10-26): for every input outside the domain that the section names, the
operation panics, so the section is exact. A panic the section calls debug-only is also proven
absent from a release build on the same inputs: no panic and no arithmetic overflow there. Where
the proofs found a section claiming more panics than the code has, the section was corrected
(12 corrections, and 3 sections added where the code panics undocumented; listed in the inventories and in [`COVERAGE.md`](COVERAGE.md)).

model's encoding, the library's decoder agrees with the model's decoder, and the model's

### Links between the Verus copies and the library

Verus proves restated copies of the variable-length codecs (`deductive/`). Three links tie
each copy to the library function it restates
([`deductive/README.md`](deductive/README.md)):
- **bounded agreement**: Kani checks that the copy and the library give the same answer on
  every input within the bounds ([`cd_agree::a_*`](src/cd_agree.rs));
- **tested agreement**: the same on random inputs of up to 4 KiB and every C++ vector row
  (`deductive/tests/agree.rs`);
- **drift guard**: a test fails when a mirrored library function, or a constant it uses,
  changes without its copy being reviewed (`deductive/tests/drift.rs`).
