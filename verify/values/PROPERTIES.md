Sections 1–3 are spec 004's (`Cell`, `s1::Interval`, the generic laws); sections 4–5 are
spec 005's (`r1::Interval` against `verify/src/real_spec.rs`, `s2::Rect` against
`verify/src/rect_spec.rs`; field definitions in

`s1::Angle` against `verify/src/angle_spec.rs`; `specs/007-formal-verify-chord-angle-angle/
data-model.md` §4). Spec 007 adds a status, `proven-by-enumeration`: the property's domain is
one `i32`, and a named release-mode test checks every value of it
(`verify/tests/angle_enumeration.rs`; spec 007 FR-008).

In plain language and grouped by kind of guarantee, with the other catalogues:
[`PROPERTIES_BY_KIND.md`](../PROPERTIES_BY_KIND.md).

The functional properties of the two value types, each stated against an independent
reference description: `verify/src/cell_spec.rs` (a cell is its identifier's decomposition in
001's model, with upstream's u-v projection) and `verify/src/arc_spec.rs` (an interval is the
set of points it denotes). Both are written from upstream C++ at `v0.14.0-40` and checked
against the C++ vectors by `verify/tests/values_spec_vs_cpp.rs`. Field definitions:
`specs/004-formal-verify-cell-interval/data-model.md` §4.
