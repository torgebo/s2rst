# Property Catalogue: `s2rst::s2::CellUnion` (FR-005)

In plain language and grouped by kind of guarantee, with the other two catalogues:
[`PROPERTIES_BY_KIND.md`](../PROPERTIES_BY_KIND.md).

The functional properties of `CellUnion`, each stated against the reference model of a union,
`verify/src/union_spec.rs`: the set of leaf cells it covers (FR-006). The model is written from
upstream `s2cell_union.h`/`.cc` on top of 001's cell model and is checked against the C++
vectors by `verify/tests/union_spec_vs_cpp.rs`. Field definitions:
`specs/002-formal-verify-cell-union/data-model.md` §4 (which extends 001's §4).

`covers(U, x)` is "the leaf with index `x` lies in some member of `U`". A property asserted for
a symbolic leaf holds for every leaf. Outputs of the implementation are read only through
`CellId::range_min`/`range_max` (001's P-RANGE-01) and `spec::decompose` (data-model §7).

**Status values**: `proven` (the whole domain) | `proven-within-bounds` (a union-size,
byte-length or loop bound leaves part of the domain uncovered; `Bound` says which, and which
tests exercise it) | `not-proven (<reason>)`.

**SC-003 denominator**: the 23 entries whose operations are all in scope. P-USET-04 and
P-URANGE-01/02/03 name an operation that is a tool-limit exclusion, so they are outside it.
